# MELT: 일상의 온도를 결정하는 가구 큐레이션

## 1. Project Overview
* **프로젝트명**: MELT
* **개요**: 모던하고 따뜻한 원목 감성을 지향하는 가구 브랜드 'MELT'의 브랜드 메인 페이지입니다.
* **목표**: 사용자가 공간의 안락함을 직관적으로 느낄 수 있도록 디자인 시스템을 구축하고, 사용자 인터랙션을 강화하여 완성도 높은 브랜드 경험을 제공하고자 했습니다.
* **제작 기간**: 1인 프로젝트 (브랜딩, 디자인, 퍼블리싱 전 과정 수행)

## 2. Concept & Design
* **브랜드 컨셉**: '일상의 온도를 녹이는(Melt) 가구'.
* **디자인 키워드**: 아이보리 톤, 현대적 모던함, 불규칙한 조형미, 과감한 타이포그래피.
* **디자인 특징**: 심심할 수 있는 모던한 레이아웃에 불규칙적인 도형과 큰 폰트를 배치하여 시각적 리듬감을 부여했습니다.

## 3. Tech Stack
* **Language/Markup**: HTML5, CSS3(SCSS), JavaScript(ES6+)
* **Library**: Swiper.js
* **Tool**: Figma

## 4. Key Features
* **데이터 기반 렌더링**: `data.js`를 활용하여 정적인 코드 대신 동적 데이터 바인딩 방식으로 섹션을 구현하여 유지보수 효율을 높였습니다.
* **반응형 인터랙션**: 모바일 환경을 고려한 쇼룸 제품 상세 뷰 및 인터랙션 로직을 구현했습니다.
* **스크롤 인터랙션**: `IntersectionObserver`를 활용해 성능 최적화된 스크롤 등장(Reveal) 애니메이션을 적용했습니다.
* **커스텀 UI/UX**: 무한 반복되는 핫스팟 애니메이션 및 커스텀 커서 팔로우 효과로 몰입감을 높였습니다.

## 5. Troubleshooting
* **iOS 배경 렌더링 오류**: `background-attachment: fixed` 사용 시 모바일 브라우저에서 배경이 깨지는 현상을 미디어 쿼리를 통한 속성 분기 처리(`scroll`)로 해결했습니다.
* **동적 애니메이션 타이밍 이슈**: HTML 생성 직후 관찰자(Observer)를 재할당하여, 동적으로 추가된 요소들도 스크롤 애니메이션이 정상 동작하도록 개선했습니다.
* **브라우저 자동 링크화 방지**: 모바일 브라우저가 텍스트를 전화번호나 주소로 잘못 인식하는 문제를 메타 태그(`format-detection`)와 CSS `color: inherit` 설정을 통해 해결했습니다.

## 6. Retrospective
* 1인 프로젝트로서 기획부터 완성까지 전체 프로세스를 조율하며 퍼블리싱의 완성도를 높이는 경험을 했습니다. 데이터 관리와 브라우저별 특수성 처리에 대해 깊이 배울 수 있는 계기가 되었습니다.
